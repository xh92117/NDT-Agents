## Corrective action

D-002 tracks a targeted correction: generated Office ZIP members use one fixed creator system,
permission mode, timestamp, ordering, and compression policy. Regression tests validate those
fields for all 72 Office fixtures. DOCX, XLSX, and PPTX packages are generated and normalized in
memory, compared with the existing bytes, and published through a same-directory working file only
when content changed. This avoids direct replacement writes through the Office libraries and
provides one bounded atomic publication point. Text generators remain fixed to UTF-8 with LF, and
the fixture tree must contain no uncataloged or temporary files. A new immutable commit and
successful remote CI run are required before S0-08 returns to its external-approval blocker state.
