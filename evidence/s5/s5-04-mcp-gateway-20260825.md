## Implemented boundary

- Application-owned registrations bind exact local `mcp+local` or remote HTTPS endpoint, server and
  namespace, audience, policy, permission, credential purpose, discovery lifetime, capabilities,
  schemas, side effects, destinations, streaming, async support, and registration hashes.
- Unsafe scheme, credentials, literal IP, localhost, fragment, query, unsafe port, malformed domain,
  deployment mismatch, plaintext token fields, tampered registration, and unapproved destination
  fail closed.
- Every discovery, capability invoke, poll, and cancel operation is a separate shared-registry tool.
  Definition schemas bind the static server, capability, and operation hashes, so a registration
  change produces a new registry version.
- Discovery is separately metered, untrusted, bounded, exact-match only, and cannot mutate the
  registry or expand permission. A five-minute default and one-hour hard lifetime apply to new
  work. Prior exact manifests remain only for already-bound async poll or cancel operations.
- Registry permission, network, secret-purpose, destination, approval, idempotency, timeout,
  concurrency, physical-call budget, result validation, and hash-only audit occur before gateway
  credential or transport use where applicable.
- Remote credentials are short-lived, exact-scope, user, task, run, permission-version, audience,
  capability-permission, secret-purpose, and policy bound. Their secret value is excluded from
  serialization and only reaches the injected transport.
- Async launch is a serial idempotency-keyed reversible operational side effect. Opaque local
  handles bind the exact scope, task, run, server/capability versions, input hash, discovery hash,
  and private remote task identity. Poll and cancel revalidate all bindings.
- Async state is monotonic. Exact cancellation replay uses the registry journal; other terminal
  replay is denied. Disconnect preserves pending state and permits a later authorized poll.
- Stream chunks require contiguous indexes, one media type, bounded count and UTF-8 bytes. MCP
  summaries, outputs, and stream text remain explicitly `UNTRUSTED`.
- Oversized completion requires an immutable exact-scope artifact whose size and SHA-256 bind the
  canonical completed payload; only a bounded summary and artifact reference enter the result.
- Wrong-server, malformed, output-schema, stream, artifact, credential, provider, disconnect,
  cancellation, and timeout failures are typed and contain no provider detail or credential value.
