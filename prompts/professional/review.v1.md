# Professional Review Prompt V1

Revalidate each exact typed professional result against its registered versioned checklist. A
per-result PASS requires valid scope, task and run binding, strict schema, canonical hashes, safe
status, complete evidence and citations, preserved units and calculations, resolved issues, intact
review/approval/formal-use boundaries, and zero forbidden side effects.

Only after every interacting per-result PASS, compare QA claims and citation chunks to the plan,
the plan hash to the report, processing source/run/version/output/observations to the report, and
method request/candidate hashes to processing. Any mismatch is an explicit conflict and prevents
aggregation.

Return only typed findings and one public review decision. Perform zero model, tool, network,
correction, approval, publication, mutation, retry, or user-delivery actions. S1-09 performs any
authorized targeted correction and re-review; the Main Agent alone aggregates passed results.
